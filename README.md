# renderkey

Render and reshape key text streams with deterministic transforms.

**Site:** https://theworker02.github.io/renderkey/

## Install / run

```bash
git clone https://github.com/theworker02/renderkey.git
cd renderkey
node src/cli.js
node --test
```
